# Data Product Operator v2.0.1

Team Loop validator catch-up. dpm_os PR #13 merged after the commit that v2.0.0 copied in, so its changes were missing. They are now in Team Loop.

- **Context provenance.** A populated context file needs a provenance tag, or `Unknown`, under its `## Provenance` section. The validator reports a missing tag. The write hook warns without blocking.
- **One file manifest.** `python3 scripts/validate.py --manifest` prints every file the scaffold ships. A test fails when the scaffold and the manifest disagree.
- **Summary.** `python3 scripts/validate.py --summary <dir>` lists populated context sections and tagged files.
- **Uninstall.** [team-loop/docs/install.md](../../team-loop/docs/install.md) now removes exactly the files in the manifest.

Existing workspaces: run `python3 scripts/validate.py .` after you update. Populated context files with no provenance tag now show up as findings.

Source: [dpm_os #13](https://github.com/hollandkevint/dpm_os/pull/13).
